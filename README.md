# Java-Swing-GUI-Programs
A collection of Java Swing GUI programs demonstrating basic GUI components, event handling, forms, calculators, and window operations. Includes practical programs using JFrame, JLabel, JTextField, JButton, JMenu, JTextArea, MouseListener, KeyListener, ItemListener, and WindowListener. 
# Java Swing GUI Programs

This repository contains a collection of Java GUI programs developed using Swing as part of my college practical work. These programs demonstrate the use of GUI components, layout management, and event handling in Java.

## Programs Included

1. **Login Form** – Create a login form using JFrame, JLabel, JTextField, JPasswordField, and JButton.
2. **Menu and Submenu** – Create menus, submenus, and menu items using JMenuBar, JMenu, and JMenuItem.
3. **User Registration Form** – Design a registration form using Swing components without using a layout manager.
4. **Sum and Average Calculator** – Calculate the sum and average of three numbers using text fields and buttons.
5. **Simple Calculator** – Perform basic arithmetic operations using Swing components.
6. **Sum and Difference Using MouseAdapter** – Calculate the sum and difference of two numbers using mouse events.
7. **WindowListener Demonstration** – Demonstrate window events using WindowListener.
8. **Square Root and Cube Root Calculator** – Calculate the square root and cube root of a given number.
9. **Character and Word Counter** – Count the total characters and words in a TextArea using KeyListener.
10. **Hobbies Selection** – Display selected hobbies using ItemListener.

## Technologies Used

- Java
- Java Swing
- AWT Event Handling

## Purpose

To practice Java GUI programming, understand Swing components, and learn event handling through simple practical applications.
